# 🕹️ OJ运营模拟器 · 墨韵

一个融合经营策略与中式恐怖元素的在线评测系统（OJ）运营模拟游戏。

## 🎮 在线体验

👉 **[点击开始游戏](https://myzlm.github.io/zlm/)**

## 🆕 v2.0 更新内容

- 💾 **存档系统**：每月结算自动保存，支持手动保存/读取、存档导出/导入（JSON 文件）、开局继续游戏
- ⌨️ **键盘快捷键**：`空格`/`N` = 进入下个月，`1-9` = 切换功能页签，`S` = 保存存档（输入框聚焦时自动失效）
- 📱 **移动端适配**：新增平板/手机断点，面板自动堆叠、页签横滑、触控目标加大

## 📖 游戏简介

你将扮演一个 OJ 平台的站长，从零开始搭建服务器、招募团队、开发功能、举办比赛，同时还要应对资金压力、服务器过载、黑客攻击…… 如果你足够胆大，可以进入 **中式恐怖模式**，体验阴气、纸钱、跳吓、假蓝屏等诡异事件。

## ✨ 核心玩法

- 🖥️ **服务器管理**：购买核心、扩容硬盘、升级架构
- 👥 **人才招募**：10种员工，平衡研发/学术/社区产出
- 🧩 **功能研发**：解锁难度分级、题解系统、API、网校等
- 🏆 **赛事运营**：举办比赛吸引用户，积累题库
- 🏦 **银行系统**：贷款、定期存款、活期利息
- 💰 **税务精算**：手动核算税款或自动扣除
- 🏫 **网校管理**：开设课程获得稳定收入
- 🤝 **风险合作**：6种合作类型，高风险高回报
- 📊 **账簿导出**：导出日志与月度收支
- 🧠 **解密挑战**：编程谜题赢取奖励

## 👻 中式恐怖模式

切换主题至 **🏮中式恐怖** 即可进入：

- 🌑 阴气值、阴德值、纸钱体系
- 🔮 烧纸驱阴、黄符护体、阴间合作
- 📞 鬼来电、午夜打印、血月降临等恐怖事件
- 💀 全屏锁定、无法退出、假蓝屏死机
- 🎃 随机跳吓、语音播报、文件删除模拟

## 🧱 技术栈

纯前端，无依赖：

- HTML5 + CSS3（10套主题变量）
- 原生 JavaScript（游戏逻辑、音效合成）
- Web Speech API（恐怖模式语音）
- Web Audio API（音效与氛围音）

## 🚀 部署到 GitHub Pages

1. 将仓库克隆到本地或直接在网页端创建。
2. 上传以下文件到根目录：
   - `index.html`
   - `style.css`
   - `script.js`
3. 进入仓库 **Settings → Pages**，Source 选择 `main` 分支，文件夹选择 `/ (root)`，点击 **Save**。
4. 几分钟后即可通过 `https://你的用户名.github.io/仓库名/` 访问。

> 如果想直接在线编辑，可以在仓库页面按 `.` 键打开 Web 版 VS Code。
